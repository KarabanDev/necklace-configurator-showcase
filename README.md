# Конструктор колье

Подвески на цепочке, висячее и встроенное крепление с поворотом по диагонали, совместимость коллекций и пересчёт стоимости.

![Колье с подвесками и выбором крепления](cover.png)

## Работа конструктора

![Выбор и перемещение подвесок на цепочке](walkthrough.gif)

[Смотреть видео](walkthrough.mp4)

- Выбор металла и длины цепочки.
- Размещение и перенос подвесок между семью позициями.
- Переключение висячего и встроенного крепления.
- Проверка совместимости коллекций.
- Изменение цен через CSV и автоматический пересчёт суммы.
